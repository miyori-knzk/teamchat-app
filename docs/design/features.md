# チームチャットアプリ 機能一覧

根拠の書き方: `spec 3-2` は `docs/spec.md` の節番号、`*.html` は `mockup/` の画面、`guide 4` は `mockup/design-guide.md` の節番号です。

|:---|:-----|:-----------|:-----|

## 今回作らないもの

| 作らないもの | 理由 | 根拠 |
|:-------------|:-----|:-----|
| 新着メッセージの自動表示（画面を開いたままで届く） | 今回は画面を開き直して確認できれば十分 | spec 4 |
| 通知（メール・スマートフォンへの通知） | まずは社内で使い始められる形を優先したい | spec 4 |
| 1対1のダイレクトメッセージ | チャンネルでの会話に絞りたい | spec 4 |
| ファイル・画像の添付 | 文章のやり取りに絞りたい | spec 4 |
| メッセージへのリアクション（絵文字を付ける） | 会話ができることを優先したい | spec 4 |
| 未読・既読の管理 | 会話ができることを優先したい | spec 4 |
| 管理者による全体管理（利用者の停止、他人のチャンネルの管理） | 運用が固まってから考えたい | spec 4 |
| 書き込み・変更ができるAPI | 公開APIは読み取り専用の2つだけでよい | spec 3-7 |
| 公開チャンネルのメンバー追加・削除 | 公開チャンネルは誰でも見られるので不要 | spec 3-3 / members.html の注記 |
| チャンネル作成後の公開範囲の変更 | 見本の編集画面に「公開範囲はあとから変更できません」とある | channel-edit.html |
| スマートフォン表示（レスポンシブ対応） | PCのブラウザだけで使う。画面の最小幅は1280px | spec 5-2 / guide 3 |
| パスワード再設定・メール認証・登録情報の変更・退会 | 仕様書・見本のどちらにもない。**作らない想定で確認中** | Q-01 |
